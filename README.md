# إعلامي · Iilami

تطبيق Android أصلي بواجهة عربية RTL، داكنة/فاتحة حسب النظام. Android 7.0+ (minSdk 24)، package: `com.comma.bulletin`.

## الوظائف
- قائمة الإعلانات: العنوان، ملخص النص، التاريخ المحلي، التصنيف، المثبّت وشارة جديد.
- تفاصيل ونص قابل للنسخ، روابط HTTPS خارجية فقط.
- سحب للتحديث وزر تحديث، حالات فارغة/خطأ، نسخة محلية للقراءة دون اتصال بعد أول تحميل.
- حالة المقروء محفوظة محلياً. لا حسابات ولا تحليلات ولا إعلانات تجارية أو صلاحيات ملفات.
- WorkManager يفحص كل 15 دقيقة تقريباً مع اتصال الشبكة. التوقيت غير مضمون في Doze وتوفير البطارية؛ الإيقاف القسري يوقف العمل حتى فتح التطبيق.
- إشعارات محلية للإعلانات ذات ID جديد بعد أول مزامنة ناجحة. أول مزامنة لا تطلق تنبيهات قديمة. Android 13+ يحتاج إذن الإشعارات؛ التنزيل والقراءة يعملان بدونه.

## المحتوى والبوت
المصدر الحالي **عام وتجريبي**:
https://bulletin-iilami-3n8e59jd000007agwak4t00004en1rq7a000000.salix-sites.comma.surf/feed.json

لا يوجد بوت مرتبط بعد ولا توكن داخل التطبيق. `FeedSource` هي نقطة الاستبدال الوحيدة؛ `HttpsFeedSource` يجلب JSON، و`Repository` يدير النسخة المحلية والمقروء والإشعارات. يمكن لبوت مستقبلاً تحديث نفس رابط JSON دون إصدار APK جديد. إذا استُبدل البروتوكول بالكامل، نفّذ `FeedSource` جديدة في `Repository`.

صيغة الإصدار 1: `{version:1, updated_at:"YYYY-MM-DDTHH:mm:ssZ", items:[{id,title,body,published_at,category,pinned,url}]}`. جميع التواريخ UTC بتنسيق الثواني وZ، IDs فريدة وثابتة، URL فارغ أو HTTPS. حد 1MiB و500 إعلان. JSON غير صالح أو خطأ HTTPS لا يستبدل آخر نسخة صالحة. تعديل إعلان بالـID نفسه لا يطلق تنبيهاً جديداً.

المحتوى الحالي توضيحي وليس أخباراً أو مواعيد رسمية. رابط عام: لا تنشر بيانات خاصة فيه. البوت المستقبلي يجب أن يحتفظ بالتوكن على الخادم، لا في APK.

## بناء وتوقيع
JDK 17، Gradle 8.9، Android SDK 35. نفّذ `gradle testDebugUnitTest lintDebug assembleDebug`. Release: احفظ keystore خاصاً خارج Git ومرّر `SIGNING_STORE` و`SIGNING_PASSWORD` (alias `iilami`). للبناء الآلي اضبط GitHub Actions secrets: `KEYSTORE_B64` و`SIGNING_PASSWORD`. لا تولّد مفتاحاً جديداً لكل تحديث، وإلا لن يُقبل التحديث فوق النسخة السابقة.

Actions يشغّل اختبارات parser وAndroid lint، يبني APK release موقّعاً، يتحقق بـapksigner وaapt وينشره مع SHA256. لا تدّعِ اختبار واجهة أو إشعارات على جهاز فعلي ما لم يُنفّذ ذلك؛ اختبارات الوحدة وlint لا تثبتان تجربة الهاتف.
